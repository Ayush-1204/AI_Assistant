Neural Network Architecture

The architecture of a Deep Neural Network (DNN) dictates how it processes information. In this document, we outline the foundational layers proposed for the Sprint Alpha model, focusing on optimizing gradient flow during backpropagation.

# 1. Forward Propagation Setup

The input matrix $X$ is fed through a series of hidden layers. Each layer applies a linear transformation followed by a non-linear activation function. We are currently evaluating GeLU over standard ReLU for the intermediate layers to mitigate the dying ReLU problem.

python 
import torch
import torch.nn as nn

class AlphaNet(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim):
        super(AlphaNet, self).__init__()
        # Layer definitions
        self.fc1 = nn.Linear(input_dim, hidden_dim)
        self.activation = nn.GELU()
        self.fc2 = nn.Linear(hidden_dim, output_dim)

    def forward(self, x):
        x = self.fc1(x)
        x = self.activation(x)
        x = self.fc2(x)
        return x
